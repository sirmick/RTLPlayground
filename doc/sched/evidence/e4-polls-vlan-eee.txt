         power cut (dotx_dx_1009n)   the boot               2, last 03f8
  Each finishes (prompt or reply), is counted with its register in
  `health tasks` ("hw timeouts N last 0xREG"), and works again once
  released, with no new timeout. The stat count is large because every
  later STAT_GET in a step gives up at once (hw_stuck) and is still
  counted. At 6ca124c (before the timeouts) the table hold hangs: `vlan
  30` never returns, and the console then shows a boot (the software
  watchdog).
  Only an RTL8373N board without 10G ports writes rtl8224_sds_write
  (rtl837x_init.c), and rtlsim models no 8224, so the test fakes both
  IDs. After that boot the first console reply comes back as link lines
  only; the test sends `version` first.
